# Data licensing & purge procedure

This is how the project follows the data providers' license terms. It is my reading
of the terms as of October 2026, **not legal advice**. Re-read the current terms
before each subscription.

## Sharadar personal-use license: the parts that matter here

Source: <https://sharadar.com/terms>

| Topic | What the license says (summarized) | How the project complies |
|---|---|---|
| Who may use it | Natural persons, personal use only. No professional work, consulting, managing others' money, or use on behalf of an employer or other entity | Personal research and portfolio project only. A job that uses this data for clients needs a commercial license |
| Sharing | No publishing, redistributing or sharing the data, or derivative data that lets someone reverse-engineer it | The raw data and the `full/` output tier never leave `data/` and `outputs/`, both of which are git-ignored |
| Public display | Displayed data needs the attribution "Data from Sharadar.com" linked to sharadar.com. Research outputs and summary statistics need no attribution | Public outputs carry the attribution anyway |
| After termination | Stop using the data. Within **30 days**, delete all copies and any dataset that could reproduce Sharadar tables. Sharadar may ask for an affidavit | `python -m screener purge --provider sharadar` deletes it and writes a purge log you can use to support an affidavit |
| What you may keep | "Research outputs, backtest results, models, summary statistics, trade logs and similar derived works" that cannot reproduce the data | The `retained/` and `public/` tiers |

## Output tiers

| Tier | Contents | After cancelling Sharadar |
|---|---|---|
| `data/raw`, `data/store`, `data/cache` | Downloads, normalized tables, computed metrics | **Deleted by purge** |
| `outputs/runs/*/full/` | Everything, including raw figures (cash, debt, market cap, price) | **Deleted by purge** (marked `license_scope: sharadar` in `TIER.json`) |
| `outputs/validation/*` (detail) | Side-by-side provider values | **Deleted by purge** |
| `outputs/runs/*/retained/` | Ranks, scores, pillar scores, ratios, growth rates, flags, sector medians, charts | Kept |
| `outputs/runs/*/public/` and `portfolio/` | Ranks, composite and pillar scores, grades, flag names, sector summary statistics, charts | Kept, and safe to publish |

`retained/` keeps per-company ratios (margins, growth rates, multiples). I read
these as derived research outputs that can't reproduce Sharadar's tables, but it's
a judgment call. If you want to be stricter, keep only `public/` and delete
`retained/` as well.

## What goes on GitHub

**Published:** code, `config/`, `docs/`, `tests/` (synthetic and hand-made fixtures only), and `portfolio/`.

**Never published:** `data/`, `outputs/`, `compliance/`, `.env`, `*.parquet`, `*.zip` and `*.gz`. All of these are git-ignored.

Before every push:

```bash
python -m screener check-public      # exits non-zero if anything licensed would be published
```

To run it automatically: `cp scripts/pre-commit .git/hooks/pre-commit && chmod +x .git/hooks/pre-commit`

## Cancellation checklist

1. Run the final screens: `python -m screener run --provider sharadar`.
2. Export portfolio files: `python -m screener export-portfolio`.
3. Check what will be deleted: `python -m screener purge --provider sharadar --dry-run`.
4. Cancel the subscription.
5. Purge within 30 days. Doing it on the day you cancel is simplest: `python -m screener purge --provider sharadar`.
6. Keep the purge log in `compliance/`.
7. Check that nothing remains: `python -m screener status` should show "no local data" for sharadar.
8. Also delete any copies you made outside this folder (exported spreadsheets, backups, Time Machine snapshots of `data/`).
